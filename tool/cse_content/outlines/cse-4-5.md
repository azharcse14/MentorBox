# Course: Compiler Design  (level id "deep-cse-4-5", lesson ids "deep-cse-4-5-01".."-25")
Builds on Theory of Computation (deep-cse-3-5: DFA/NFA, subset construction, minimization, regex, CFG, derivations, ambiguity, PDA),
Data Structures (deep-cse-2-2: stack, tree, hash table), Microprocessors & Assembly (deep-cse-3-3: registers, stack, CALL/RET) and
Computer Architecture (deep-cse-3-2). Automata and grammar theory is only recapped; the focus here is how a compiler USES it:
building a lexer, parsing algorithms with worked tables (LL(1), SLR, LR(1), LALR), syntax-directed translation, type checking,
intermediate code, runtime environments, code generation and optimization. Running examples: position = initial + rate * 60 and the
expression grammar E -> E + T | T, T -> T * F | F, F -> ( E ) | id.
01 What a compiler is: translators recap (compiler, interpreter, assembler, hybrid/bytecode), the problem compilers solved, history (Hopper A-0, FORTRAN 1957), what makes a good compiler, course map
02 Structure of a compiler: the six phases traced on position = initial + rate * 60, symbol table and error handler, analysis/synthesis, front end/back end, passes, cousins (preprocessor, assembler, linker, loader), compiler construction tools, bootstrapping and cross compilers with T-diagrams
03 Lexical analysis: job of the lexer, why separate from the parser, tokens/lexemes/patterns/attributes, token stream for a C line, whitespace and comments, input buffering with buffer pairs and sentinels, lexical errors and recovery
04 Specifying and recognizing tokens: regex recap, regular definitions (letter, digit, id, number), transition diagrams for relop, id and unsigned numbers, keywords vs identifiers (reserved word table), longest match and rule priority, lookahead
05 From regular expressions to a lexer: Thompson construction recap, subset construction recap, direct regex-to-DFA with nullable/firstpos/lastpos/followpos worked on (a|b)*abb, table-driven lexer loop, DFA minimization brief, Lex/Flex file structure and yytext/yylex
06 Syntax analysis: role of the parser, CFG recap, derivations and parse trees, ambiguity and the dangling else, writing an unambiguous expression grammar with precedence and associativity, parser types, syntax error recovery (panic mode, phrase level, error productions, global correction)
07 Top-down parsing and grammar preparation: recursive descent idea, backtracking and why it is slow, left recursion (immediate and indirect) elimination worked, left factoring worked, a hand-written recursive descent parser for expressions
08 FIRST and FOLLOW: why we need them, rules for FIRST (with ε) and FOLLOW, step-by-step computation on the expression grammar, common traps
09 LL(1) parsing: building the predictive table, LL(1) conditions, table-driven parser with explicit stack, full trace of id + id * id, non-LL(1) grammars and conflicts, error recovery with synchronizing sets
10 Bottom-up parsing: reductions, rightmost derivation in reverse, handles and handle pruning, shift-reduce parser with stack trace, shift/reduce and reduce/reduce conflicts, operator-precedence parsing brief
11 LR(0) items and the SLR table: why LR, augmented grammar, items, closure and goto worked, canonical LR(0) collection for the expression grammar (12 states), SLR table construction with FOLLOW
12 Running an LR parser and the limits of SLR: LR driver algorithm, full trace of id * id + id on the SLR table, how conflicts appear, the S -> L = R | R grammar where SLR fails, LR family power
13 Canonical LR(1) and LALR(1): LR(1) items with lookahead, closure rules, the S -> C C grammar (10 states), merging cores into LALR (7 states), reduce/reduce from merging, comparison of LR(0)/SLR/LALR/LR(1) sizes and power
14 Parser generators and ambiguous grammars: Yacc/Bison file structure, $$ and $1, precedence and associativity declarations, dangling else resolved by shift, LR error recovery with the error token, Lex + Yacc working together, desk calculator
15 Syntax-directed definitions: attributes, semantic rules, synthesized vs inherited, annotated parse tree for 3 * 5 + 4, inherited attributes for declarations (int a, b, c), dependency graphs and evaluation order, S-attributed and L-attributed SDDs
16 Syntax-directed translation schemes and syntax trees: actions inside productions, postfix SDT on an LR stack, infix to postfix translation, building abstract syntax trees with Leaf/Node, DAGs for expressions with value numbering
17 Type checking: types and type expressions, type systems, static vs dynamic and strong vs weak, type rules for expressions/arrays/functions/statements, coercion and widening, structural vs name equivalence, overloading and polymorphism brief
18 Intermediate representations: why IR (m x n problem), syntax tree and DAG, postfix, three-address code instruction forms, quadruples, triples and indirect triples on a = b * -c + b * -c, SSA form and phi functions intro
19 Translating declarations, expressions and arrays: widths and offsets in the symbol table, nested scopes and symbol table chaining, three-address code for assignments, array address computation (1D and row-major 2D) worked, type conversions in code
20 Control flow and backpatching: boolean expressions with jumps, short-circuit evaluation, if/if-else/while translation with labels, backpatching with truelist/falselist/nextlist worked, switch statements (jump table vs compare chain), function calls (param/call)
21 Runtime environments: storage layout (code, static, heap, stack), activation trees and records, calling and return sequences, access links and displays for nested procedures, parameter passing (value, reference, value-result, name), heap management and garbage collection brief
22 Code generation basics: issues (instruction selection, register allocation, ordering), a simple target machine and instruction cost, basic blocks with leaders, flow graphs, next-use information, a simple code generator with register and address descriptors
23 Register allocation and peephole optimization: why registers matter, liveness and interference graph, graph colouring with k registers, spilling, instruction selection by tree patterns brief, peephole optimizations (redundant load/store, jumps over jumps, algebraic simplification, strength reduction)
24 Machine-independent optimization: local vs global, common subexpression elimination, copy propagation, constant folding and propagation, dead code elimination, loop optimizations (code motion, induction variables, strength reduction), DAG-based local optimization worked
25 Data-flow analysis and wrap-up: gen/kill framework, reaching definitions, live variables, available expressions, iterative algorithm worked, dominators and natural loops, JIT compilation, GCC and LLVM, course recap and what next
