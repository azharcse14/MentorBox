# Course: Mobile Application Development  (level id "deep-cse-5-4", lesson ids "deep-cse-5-4-01".."-25")
Builds on OOP (deep-cse-2-1), Data Structures, Operating Systems (deep-cse-4-1: processes, threads, sandboxing idea), DBMS (deep-cse-4-2: SQL),
Computer Networks (deep-cse-4-3) and Software Engineering (deep-cse-4-4: testing, process). HTTP/REST/JSON details, JavaScript and web security
live in Web Engineering (deep-cse-5-3); usability and design principles live in Human Computer Interaction (deep-cse-5-5): recap and point there.
Examples: Flutter/Dart as main code language, small Kotlin (Android) snippets for comparison, Swift/iOS at concept level. No SDK version numbers unless certain.
01 What mobile app development is: what makes mobile different (small touch screen, battery, flaky network, sensors, app stores, sandbox), kinds of apps, the stack from OS to UI, Bangladesh's mobile-first users, course map
02 The two platforms, Android and iOS: short history, Android stack (Linux kernel, HAL, ART, framework), iOS layers, sandboxing, languages (Kotlin/Java, Swift), tools (Android Studio, Xcode on macOS), fragmentation vs controlled hardware, market in Bangladesh
03 Native vs cross-platform vs hybrid vs PWA: how each runs (native code, Flutter's own renderer, React Native's native widgets, WebView apps, PWAs with service workers), Kotlin Multiplatform idea, trade-offs table in words, how to choose
04 Tools and your first project: SDKs, emulator vs real device, USB debugging/adb, Flutter project layout (pubspec.yaml, lib/main.dart, android/, ios/), Android project (manifest, Gradle, res), build outputs APK/AAB/IPA, debug vs release, hot reload
05 Dart essentials for app developers: variables, var/final/const, types, sound null safety (?, !, late, required), functions and named parameters, classes and constructors, lists/maps, lambdas, a Future preview
06 Android app components and intents: Activity, Service, BroadcastReceiver, ContentProvider, the manifest, explicit and implicit intents, intent filters, share sheet, how Flutter sits inside one Activity
07 App lifecycle: why the OS kills apps, Activity callbacks onCreate..onDestroy with a worked sequence, rotation and configuration changes, process death and saved state, ViewModel survival, iOS app states, Flutter AppLifecycleState
08 Building UI I, imperative vs declarative: view trees, XML layouts + findViewById vs Jetpack Compose/SwiftUI/Flutter, UI = f(state), Flutter widget tree, StatelessWidget vs StatefulWidget, build() and rebuilds, element/render tree idea
09 Building UI II, layout, screens and input: constraints-go-down sizes-go-up, Row/Column/Stack/Expanded, padding, dp/density, screen sizes and orientation, responsive layouts, Material and Cupertino, text fields, keyboards, forms and validation, gestures
10 Navigation: screens and the back stack, Flutter Navigator push/pop and returning results, named routes and router packages, Android back button, Jetpack Navigation and iOS navigation stacks brief, tabs, drawers, bottom navigation, deep links
11 State management: what state is, ephemeral vs app state, setState, lifting state up, unidirectional data flow, InheritedWidget/Provider/Riverpod/Bloc overview, Compose state hoisting, ViewModel with StateFlow, choosing simply
12 App architecture: separation of concerns, MVC, MVP, MVVM, repository pattern, layers (UI, domain, data), dependency injection, a worked feature split into layers, folder structure
13 Lists, images and smooth UI: frame budget (16.7 ms at 60 Hz), jank, lazy lists (ListView.builder, RecyclerView, LazyColumn, cell reuse), keys, pagination/infinite scroll, image loading and caching, avoiding needless rebuilds
14 Asynchronous programming: the main/UI thread, ANR, threads, Futures and async/await, error handling, Streams, Kotlin coroutines and dispatchers, Dart isolates for heavy work, cancelling work when screens close
15 Networking and REST APIs: HTTP recap (point to Web Engineering), INTERNET permission, http/dio and Retrofit, JSON decode to model classes, status codes, timeouts and retries, loading/error/empty states, pagination, HTTPS by default
16 Local storage I, key-value and files: why store locally, SharedPreferences/DataStore/UserDefaults, app-private files vs shared storage, cache vs documents, JSON files, sizes and limits, what not to store
17 Local storage II, SQLite: when you need a database, tables and SQL recap, sqflite, Room, Core Data/SwiftData brief, DAO idea, transactions, schema versions and migrations, indexing, a notes app worked example
18 Offline-first and sync: local database as source of truth, cache strategies (cache-then-network, stale-while-revalidate), outbox/sync queue, conflict handling (last-write-wins, merge), connectivity checks, Bangladesh low-signal examples
19 Permissions and privacy: sandbox recap, normal vs dangerous/runtime permissions, asking at the right time, rationale, denial and "don't ask again", Info.plist usage strings, approximate vs precise location, data minimisation, privacy labels and Data safety, tracking consent
20 Sensors, location and camera: sensor framework (accelerometer, gyroscope, magnetometer, proximity, light), sampling and battery, GPS/Wi-Fi/cell location and accuracy, geofencing idea, maps, camera and image picker, QR scanning, battery cost
21 Notifications and background work: local vs push notifications, FCM and APNs flow, device tokens, channels and importance, notification permission, background limits, Doze idea, WorkManager and foreground services, iOS background modes brief, battery-friendly design
22 Mobile security: threat model (lost phone, reverse engineering, network attackers, malicious apps), secure storage (Keystore/Keychain), HTTPS/TLS and certificate pinning idea, never hard-code secrets, tokens and refresh, obfuscation, root/jailbreak, OWASP Mobile Top 10 mention, web security pointer
23 Testing, debugging and profiling: test pyramid on mobile, unit/widget/integration tests in Flutter, JUnit/Espresso and XCTest brief, emulators and device farms, logs and logcat, breakpoints, DevTools and profilers, memory leaks, crash reporting, app size reduction
24 Accessibility and localization: screen readers (TalkBack, VoiceOver), semantic labels, touch target size, contrast, text scaling, i18n vs l10n, string resources and ARB files, Bangla text and fonts, Bangla digits/dates/currency, plurals idea, RTL mention, HCI pointer
25 Publishing, monetization and wrap-up: release builds, app signing and keys, versionCode/versionName, Play Console tracks and staged rollout, App Store Connect, TestFlight, review, store listing, monetization models (paid, IAP, subscriptions, ads), store billing rules, analytics and crash-free metrics, what to learn next
