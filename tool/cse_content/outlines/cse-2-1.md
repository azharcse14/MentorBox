# Course: Object Oriented Programming  (level id "deep-cse-2-1", lesson ids "deep-cse-2-1-01".."-25")
Main language Java (most common in BD 2nd-year OOP courses), with C++ OOP covered in lessons 22-23 (BUET/KUET style C++ syllabus).
01 Why OOP: procedural vs object oriented thinking, history (Simula, Smalltalk, C++, Java), objects in the real world, four pillars preview
02 Java essentials for OOP: JDK/JRE/JVM, bytecode, "write once run anywhere", main method, primitive types, operators, control flow, arrays (quick review)
03 Classes and objects: fields, methods, new, reference variables, stack vs heap, null, many objects from one class, object identity
04 Methods in depth: parameters and return values, pass-by-value (references copied), method overloading, varargs, local vs instance variables
05 Constructors and object lifetime: default vs parameterized, constructor overloading, this(...) chaining, copy constructor idea, initialization order, garbage collection
06 this, static and final: this keyword, static fields/methods/blocks, instance vs class members, final variables/constants, static counter example
07 Encapsulation and access modifiers: private/default/protected/public table, getters/setters with validation, data hiding, immutable classes
08 Strings and wrapper classes: String immutability, string pool, == vs equals, StringBuilder, common String methods, wrapper classes, autoboxing/unboxing
09 Object relationships: association, aggregation, composition, dependency; has-a vs is-a; arrays of objects
10 Inheritance: extends, super class/sub class, types (single, multilevel, hierarchical; why Java has no multiple class inheritance), super(...) and constructor order
11 Method overriding: rules, @Override, super.method(), covariant return, final methods and classes, overloading vs overriding
12 Polymorphism: compile-time vs runtime, upcasting and downcasting, dynamic method dispatch, instanceof, polymorphic arrays
13 Abstract classes: abstract methods, cannot instantiate, partial implementation, template method idea
14 Interfaces: implements, multiple interfaces, default and static methods, abstract class vs interface, functional interfaces and lambdas (intro)
15 The Object class: toString, equals, hashCode contract, getClass, clone with shallow vs deep copy
16 Packages: package and import, built-in packages (java.lang, java.util, java.io), naming conventions, access across packages, jar idea
17 Exception handling: try/catch/finally, throw vs throws, checked vs unchecked, Throwable hierarchy, custom exceptions, try-with-resources
18 Generics: generic classes and methods, type parameters, bounded types, wildcards, type safety, type erasure (brief)
19 Collections framework: List/Set/Map/Queue, ArrayList vs LinkedList, HashSet, HashMap, TreeMap, Iterator, Comparable vs Comparator
20 File I/O and streams: byte vs character streams, FileReader/FileWriter, BufferedReader, Scanner, try-with-resources, object serialization
21 Multithreading: process vs thread, Thread vs Runnable, thread lifecycle, race condition, synchronized, deadlock idea
22 OOP in C++: class syntax, default private, constructors and destructors, virtual functions and vtable idea, pure virtual and abstract class, multiple inheritance, diamond problem, virtual inheritance, friend functions
23 C++ operator overloading and templates: operator+, operator<<, rules and limits, function templates, class templates, STL intro (vector, map)
24 GUI and event-driven programming: Swing/JavaFX components, events and listeners, lambdas as handlers, MVC idea
25 Object oriented design: UML class diagrams, SOLID principles, design patterns (Singleton, Factory, Observer, Strategy), course recap and what next
