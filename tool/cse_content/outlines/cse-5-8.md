# Course: Software Testing & Quality Assurance  (level id "deep-cse-5-8", lesson ids "deep-cse-5-8-01".."-27")
Builds on Software Engineering (deep-cse-4-4), whose lessons 18-21 and 24 already introduce error/fault/failure, the seven principles,
test levels, EP/BVA/decision tables/state transition, statement/branch/path coverage, cyclomatic complexity, TDD/CI and
ISO/IEC 25010/CMMI: here those are only recapped and then taken much deeper with new worked examples. Mobile-specific testing
(Flutter widget tests, Espresso/XCTest, device farms) is in Mobile App Development (deep-cse-5-4, lesson 23); usability evaluation
methods in depth (heuristics, SUS, user studies) are in HCI (deep-cse-5-5): mention and point there.
Focus: ISTQB-style vocabulary, test design techniques with worked numbers, coverage criteria up to MC/DC and data flow,
test management (planning, defects, risk), automation (xUnit, TDD/BDD, doubles, pyramid, UI/API), non-functional testing,
CI/DevOps, metrics, process quality and QA careers.
01 Why software fails and the principles of testing: mistake/error, fault/defect/bug, failure, root cause, famous failures (Ariane 5, Mars Climate Orbiter, Therac-25), what testing is and is not, testing vs debugging, the seven principles in depth, course map
02 Quality, QA, QC and the psychology of testing: definitions of quality, QA (process) vs QC (product) vs testing, verification vs validation, cost of quality (prevention, appraisal, internal and external failure), ISO/IEC 25010 recap, independence of testing, tester mindset and communication, confirmation bias
03 Testing in the lifecycle, unit and integration testing: V-model recap, testing in Agile, shift-left, component testing scope and who does it, integration levels (component and system integration), big bang, top-down, bottom-up, sandwich, stubs and drivers, interface defects, worked integration order
04 System and acceptance testing: system testing end to end against requirements, test environment close to production, UAT, operational acceptance, contractual and regulatory acceptance, alpha and beta, entry and exit criteria, sign-off
05 Test types: functional vs non-functional, white-box (structural) testing as a type, confirmation testing (re-testing) vs regression testing, regression selection, smoke vs sanity, maintenance testing and impact analysis, test types at each level
06 Static testing: why find defects without running code, review types (informal, walkthrough, technical review, inspection), roles, Fagan inspection steps, checklists, reading rates, static analysis tools and what they find (data-flow anomalies, unreachable code, standards), benefits and success factors
07 Equivalence partitioning and boundary value analysis in depth: valid and invalid partitions, multiple inputs, weak vs strong equivalence class testing, BVA two-value and three-value, Jorgensen's normal (4n+1), robust (6n+1), worst-case (5^n) counts worked, non-numeric boundaries, mobile recharge example
08 Decision tables and cause-effect graphing: conditions, actions, rules, 2^n columns, don't-care entries and collapsing, extended-entry tables, coverage, worked loan/discount example, cause-effect graph idea, when to use
09 State transition and use-case testing: states, events, guards, actions, state diagram and state table, valid and invalid transitions, 0-switch and 1-switch coverage, worked ATM/PIN example, use-case main and alternative flows into test cases
10 Combinatorial and experience-based testing: combinatorial explosion, all-combinations vs each-choice vs pairwise, worked pairwise table (2^3 to 4 tests, 3^4 to 9 tests), orthogonal arrays, tools like PICT, classification tree idea; error guessing, fault attacks, checklist-based, exploratory and session-based testing with charters
11 White-box testing I, statement and branch coverage: control flow graph recap, statement coverage formula, branch (decision) coverage formula, worked examples where 100% statement is not 100% branch, coverage tools idea, what coverage does not tell you
12 White-box testing II, condition coverage and MC/DC: condition vs decision, condition coverage, condition/decision, multiple condition (2^n), MC/DC definition and worked example for A and (B or C), n+1 tests, short-circuit evaluation, MC/DC in avionics (DO-178C level A)
13 White-box testing III, paths, loops, data flow and mutation: path coverage and why it explodes, cyclomatic complexity recap and basis paths, loop testing (skip, once, twice, typical, max-1, max, max+1), data-flow testing (def, c-use, p-use, du-pairs, all-defs, all-uses, anomalies), mutation testing and mutation score worked
14 Test process, planning and strategy: test process activities (planning, monitoring and control, analysis, design, implementation, execution, completion), test plan contents (IEEE 829 / ISO/IEC/IEEE 29119-3 idea), strategy approaches, entry and exit criteria, estimation (metrics-based, expert-based, three-point worked), test reports
15 Test cases, suites and test data: test condition vs scenario vs case vs procedure, anatomy and qualities of a good test case, suites, traceability matrix, test data (production copies, masking, synthetic), privacy, environments, the test oracle problem
16 Defect lifecycle and bug reports: defect states (new, assigned, open, fixed, retest, verified, closed, reopened, rejected, deferred, duplicate), severity vs priority with examples, anatomy of a good bug report, defect tracking tools, triage, root cause analysis (5 whys, fishbone)
17 Risk-based testing: risk = likelihood x impact, product vs project risks, risk identification and analysis, worked risk matrix and priority ordering, how risk shapes depth and order of testing, residual risk, FMEA idea
18 Unit testing frameworks, TDD and BDD: xUnit family (JUnit, pytest, NUnit), test structure Arrange-Act-Assert, assertions, fixtures, setup/teardown, FIRST properties, TDD red-green-refactor worked (leap year), BDD and Gherkin Given-When-Then, Cucumber, ATDD
19 Test doubles: why isolate, dummy, stub, spy, mock, fake (Meszaros), state vs behaviour verification, dependency injection, worked payment-gateway example, over-mocking dangers, flaky tests and test isolation
20 Test automation pyramid and UI/E2E automation: what to automate and ROI, pyramid (Cohn) layers, ice-cream-cone anti-pattern, UI automation concepts (locators, waits, Page Object Model), data-driven and keyword-driven frameworks, record and playback, tools (Selenium WebDriver, Cypress, Playwright, Appium) at concept level, flakiness
21 API testing: what an API is, why test below the UI, HTTP methods and status codes recap, what to check (status, body, schema, headers, timing), positive and negative tests, authentication, idempotency, contract testing, tools (Postman, curl, REST Assured), worked test set for an order API
22 Performance testing: load, stress, spike, soak (endurance), scalability, volume; metrics (response time, percentiles, throughput, error rate, concurrency), Little's law worked, workload modelling, think time, bottlenecks, tools (JMeter, Gatling, k6, Locust)
23 Security testing basics: CIA triad, threats and vulnerabilities, OWASP Top 10 idea, SAST vs DAST, vulnerability scanning vs penetration testing, fuzzing, testing for SQL injection, XSS, broken authentication and access control, ethics and permission, tools (OWASP ZAP, Burp Suite) at concept level
24 Usability, accessibility and compatibility testing: usability test basics (tasks, think-aloud, small samples; depth in deep-cse-5-5), accessibility (WCAG POUR, levels A/AA/AAA, contrast 4.5:1, screen readers, keyboard), automated vs manual a11y checks, compatibility (browsers, devices, OS), localization and Bangla text testing
25 CI and testing in DevOps: continuous integration recap, pipeline stages and quality gates, fast feedback, test selection and parallel runs, flaky test quarantine, shift-left and shift-right, canary releases, feature flags, monitoring in production, chaos engineering idea, A/B testing
26 Test metrics: why measure, defect density worked, defect removal efficiency (DRE) worked, defect leakage, coverage metrics, pass rate and test progress, defect arrival and closure trends, mean time to detect/repair idea, Goodhart's law and metric misuse
27 Process quality and careers in QA: process vs product quality, CMMI five maturity levels, ISO 9001 and PDCA at concept level, TMMi idea, audits, Six Sigma brief, careers (manual tester, automation engineer/SDET, performance, security, QA lead), skills, ISTQB certification, building a portfolio, course wrap-up
