# Course: Data Structures  (level id "deep-cse-2-2", lesson ids "deep-cse-2-2-01".."-25")
01 What a data structure is: data vs information, ADT, linear vs non-linear, static vs dynamic, basic operations
02 Algorithm analysis: counting steps, time and space complexity, Big O / Omega / Theta, best/worst/average case
03 Arrays: 1D arrays, address calculation, traversal, insertion, deletion, 2D arrays, row-major vs column-major
04 Strings, matrices and sparse matrices: strings as char arrays, naive pattern matching, matrix ops, triplet form
05 Dynamic arrays and amortized analysis: capacity vs size, doubling, why append is O(1) amortized
06 Pointers, structures and dynamic memory: addresses, pointers, struct/node, malloc/free (new/delete), memory leaks
07 Singly linked list: node, head, traversal, insert at head/tail/middle, delete, search, reverse
08 Doubly and circular linked lists: prev/next pointers, circular list, header nodes, polynomial addition, array vs list
09 Stacks: LIFO, push/pop/peek, array and linked implementation, overflow/underflow, uses
10 Stack applications: parenthesis matching, infix/prefix/postfix, infix-to-postfix conversion, postfix evaluation
11 Recursion: base case, call stack, factorial, Fibonacci, Tower of Hanoi, recursion vs iteration, tail recursion
12 Queues: FIFO, enqueue/dequeue, array queue problem, circular queue, linked queue
13 Deques and priority queues: input/output-restricted deque, priority queue ideas, applications (scheduling, BFS)
14 Trees: terminology (root, leaf, degree, height, depth), binary tree types, properties, array and linked representation
15 Binary tree traversals: preorder, inorder, postorder, level order, building a tree from traversals, expression trees
16 Binary search trees: search, insert, find min/max, delete (3 cases), inorder successor, skewed BST problem
17 Balanced search trees: AVL trees, balance factor, LL/RR/LR/RL rotations, red-black trees (idea only)
18 Heaps: complete binary tree in array, max/min heap, insert, extract, heapify, build-heap, heap sort, priority queue
19 Multiway trees: B-trees (order, split), B+ trees for databases, tries for words
20 Hashing: hash functions, collisions, separate chaining, open addressing (linear, quadratic, double hashing), load factor, rehashing
21 Graphs: terminology, directed/undirected, weighted, degree, paths/cycles, adjacency matrix vs adjacency list
22 Graph traversal: BFS, DFS, connected components, cycle detection, topological sort; MST/shortest path named for Algorithms
23 Searching: linear search, binary search (iterative and recursive), complexity, sentinel, common bugs
24 Simple sorting: bubble, selection, insertion sort, stability, in-place, best/worst cases
25 Fast sorting and wrap-up: merge sort, quick sort (pivot, partition), counting/radix idea, comparison table, choosing a structure
