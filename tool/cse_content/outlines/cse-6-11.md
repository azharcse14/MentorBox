# Course: Software Project Management  (level id "deep-cse-6-11", lesson ids "deep-cse-6-11-01".."-25")
Builds on Software Engineering (deep-cse-4-4: lessons 03-07 process models, agile, Scrum/Kanban basics; 22-25 first look at WBS, CPM,
PERT, function points, basic COCOMO, risk, quality, configuration management), System Analysis & Design (deep-cse-4-6: feasibility,
requirements gathering), Software Testing & QA (deep-cse-5-8: test management, defect metrics), Operations Research (deep-cse-6-10:
lessons 15-16 CPM forward/backward pass, PERT probability and crashing in full) and Professional Ethics & Cyber Law (deep-cse-6-6:
licences, contracts, professionalism). Those are only recapped; here the focus is the manager's job: deciding, planning, estimating,
tracking money and time, handling risk and people, and closing a project well. Point forward to Final Year Project / Thesis (deep-cse-6-7)
and System Design (deep-cse-6-13). Hughes & Cotterell / PMBOK / Scrum Guide style, version-neutral, with every number checked in Python.
One running example is reused: an invented Dhaka software firm "MeghSoft" building "DhakaEats", a food-delivery app (customer app, rider
app, restaurant panel, payment), with a budget in taka and a 6-month deadline.

08 Function point analysis: why measure size by function not lines, IFPUG components (EI, EO, EQ, ILF, EIF), complexity weights table, unadjusted FP worked for DhakaEats, 14 general system characteristics and VAF = 0.65 + 0.01 x TDI worked, FP to effort via productivity and LOC via backfiring, strengths and weaknesses, use case points and story points brief
