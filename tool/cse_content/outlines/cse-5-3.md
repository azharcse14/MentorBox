# Course: Web Engineering  (level id "deep-cse-5-3", lesson ids "deep-cse-5-3-01".."-26")
Builds on Computer Networks (deep-cse-4-3: lessons 05-08 teach HTTP messages, RTT math, caching, HTTP/2-3, DNS; lesson 26 TLS), DBMS
(deep-cse-4-2: SQL, normalization, transactions; lesson 25 SQL injection) and Software Engineering (deep-cse-4-4: lesson 17 Git, lesson 21 CI/CD).
Those are only recapped from a web developer's view. Mobile Application Development (deep-cse-5-4) runs in parallel: native/Flutter apps live there,
here only PWAs are named. Focus: build a real web app end to end, front end (HTML, CSS, JavaScript) -> back end (generic Node/Express style
server, REST, database) -> auth and security -> performance, accessibility, SEO -> SPAs and deployment. Framework claims stay version-neutral.
One running example: "Bazar", a small online shop for a Dhaka grocery (product list, cart, login, orders).
01 What web engineering is: Internet vs web, client and server, browser and web server, front end / back end / full stack, static vs dynamic sites, web app vs website, the stack map (HTML, CSS, JS, server, DB), why "engineering" (process, quality, scale), course map
02 How a page reaches you, developer view: URL anatomy (scheme, host, port, path, query string, fragment), DNS + TCP + TLS recap in one paragraph, request/response in DevTools Network tab, methods and safe/idempotent, status codes a web dev meets, key headers (Content-Type, Location, Cache-Control, Authorization), cookies and attributes (Expires/Max-Age, Domain, Path, Secure, HttpOnly, SameSite)
03 HTML basics: markup idea, elements, tags, attributes, nesting, doctype and the html/head/body skeleton, meta charset and viewport, headings and paragraphs, links (absolute vs relative URLs), images and alt, lists, tables, comments, how the browser builds the DOM tree, validators
04 HTML5 semantics and media: semantic elements (header, nav, main, article, section, aside, footer, figure, time), why semantics (screen readers, SEO, maintainability), div and span, block vs inline, audio and video with controls, canvas vs SVG brief, entities, a semantic page skeleton for Bazar
05 HTML forms: form action and method, GET vs POST for forms, name/value pairs and URL encoding, input types (text, email, password, number, date, checkbox, radio, file, hidden), label for, select, textarea, button types, built-in validation (required, min, max, pattern, maxlength), enctype multipart/form-data, client validation is not security
06 CSS fundamentals: what CSS is, inline/internal/external, rule syntax, selectors (type, class, id, attribute, descendant, child, group, pseudo-class, pseudo-element), the cascade, specificity worked (a,b,c counting), !important, inheritance, units (px, %, em, rem, vw, vh), colors (hex, rgb, hsl), custom properties
07 Box model and positioning: content, padding, border, margin, width worked for content-box vs border-box, margin collapsing, display (block, inline, inline-block, none), visibility vs display none, position (static, relative, absolute, fixed, sticky), containing block, z-index, overflow, centering tricks
08 Flexbox: one-dimensional layout, container vs items, main and cross axis, flex-direction, justify-content, align-items, align-self, flex-wrap, gap, order, flex-grow/flex-shrink/flex-basis worked with numbers, navbar and card row
09 CSS Grid: two-dimensional layout, grid-template-columns/rows, fr unit worked, repeat(), minmax(), auto-fill vs auto-fit, gap, placing items with line numbers and span, grid-template-areas, implicit grid, grid vs flexbox when
10 Responsive design: mobile-first, viewport meta recap, fluid widths and relative units, media queries (min-width breakpoints, orientation, prefers-color-scheme), responsive images (max-width 100%, srcset, sizes, picture), flexible typography (clamp), DevTools device mode, CSS frameworks (Bootstrap, Tailwind) and preprocessors (Sass) as concepts
11 JavaScript basics: what JS is and where it runs (engine, browser, Node), script tag, defer/async, console, let/const/var, primitive types and objects, typeof, null vs undefined, == vs === and coercion worked, truthy/falsy, operators, if/switch, loops, template literals, strict mode
12 Functions, objects and arrays: declarations vs expressions vs arrow functions, parameters and defaults, return, scope (global, function, block), hoisting brief, closures worked (counter), objects and methods, this brief, arrays and map/filter/reduce worked, destructuring and spread, ES modules import/export, classes as syntax
13 The DOM and events: DOM tree and node types, document, querySelector/All, textContent vs innerHTML (and why innerHTML with user data is dangerous), attributes, classList, style, createElement/append/remove, events, addEventListener, event object, preventDefault, bubbling, capturing, event delegation, a Bazar cart counter
14 Asynchronous JavaScript: single thread, call stack, Web APIs, task queue and microtask queue, event loop, setTimeout(0) worked order, callbacks and callback hell, promises (pending, fulfilled, rejected, then/catch/finally, chaining), async/await, try/catch, Promise.all/allSettled/race
15 JSON, fetch and CORS: JSON syntax rules vs JS objects, JSON.parse/JSON.stringify, AJAX idea and XMLHttpRequest history, fetch GET, fetch POST with headers and body, response.ok and status (fetch does not reject on 404), loading and error states, same-origin policy, CORS headers and preflight
16 Server-side basics: what the back end does, request lifecycle on a server, server-side languages and runtimes (PHP, Python, Java, C#, Go, Node.js), Node.js and npm, a minimal Express-style app, routes, req and res objects, middleware chain, static files, body parsing, environment variables and config, logging, error handling
17 Routing, MVC and templates: route parameters vs query strings, route order, MVC (model, view, controller) traced through one request, server-side rendering with a template, layouts and partials, separation of concerns, full-stack frameworks as concepts (Laravel, Django, Rails, Spring, ASP.NET Core)
18 REST API design: resources and URIs, nouns not verbs, collections and items, method to CRUD mapping, status codes for APIs (200, 201, 204, 400, 401, 403, 404, 409, 422, 500), statelessness, filtering, sorting, pagination, versioning, idempotency, consistent JSON errors, OpenAPI docs, GraphQL in one paragraph
19 Databases from the web app: driver and connection string, connection pools, running SQL from code, parameterized queries, ORM idea (models, relations, migrations, seeding), the N+1 query problem worked, transactions for an order checkout, SQL vs NoSQL (document stores) choice, caching hot data (Redis idea)
20 Sessions and tokens: HTTP is stateless (recap), server-side sessions with a session id cookie, session stores, token-based auth, JWT structure (header.payload.signature, base64url, signed not encrypted), verifying, expiry and refresh tokens, where to keep tokens (cookie vs localStorage trade-off), logout and revocation, OAuth 2.0 and OpenID Connect "Login with Google" idea
21 Authentication and password security: authentication vs authorization, never store plain text, hashing vs encryption, salts and rainbow tables, slow password hashes (bcrypt, scrypt, Argon2), login flow, rate limiting and lockout, MFA and OTP, secure password reset tokens, role-based access control, least privilege
22 Web security: OWASP Top 10 idea, XSS (stored, reflected, DOM) with escaping and Content-Security-Policy, SQL injection worked and parameterized queries, CSRF with tokens and SameSite cookies, HTTPS/TLS and HSTS, broken access control (IDOR), validating input on the server, secrets out of code, outdated dependencies, clickjacking and security headers
23 Web performance: why speed matters, what happens while a page renders (critical rendering path: HTML -> DOM, CSS -> CSSOM, render tree, layout, paint), render-blocking resources, HTTP caching (Cache-Control, ETag, 304) from the developer side, CDNs, minification, bundling, compression (gzip, Brotli), image formats (WebP, AVIF) and sizing, lazy loading, Core Web Vitals (LCP, INP, CLS) and Lighthouse
24 Web accessibility: who benefits, WCAG and POUR, alt text, headings structure, labels, color contrast (4.5:1), keyboard access and focus, semantic HTML first, ARIA roles and attributes (first rule of ARIA), testing with keyboard, screen readers and Lighthouse
25 SPAs, frameworks and SEO: multi-page vs single-page apps, client-side routing and History API, components, props and state, declarative UI and the virtual DOM idea (React), Vue and Angular as concepts, SSR, SSG, hydration, meta-frameworks, PWA (manifest, service worker) brief; SEO: crawling, indexing, ranking, title and meta description, headings, semantic HTML, friendly URLs, sitemap.xml, robots.txt, why pure client-rendered pages can be harder for SEO
26 Deployment, version control and wrap-up: Git and pull requests recap (see deep-cse-4-4), CI/CD pipeline for a web app, environments (dev, staging, production), hosting types (shared, VPS, cloud, PaaS, static hosting), domain and DNS records (A, CNAME), HTTPS certificates (Let's Encrypt), reverse proxy (Nginx), containers (Docker) brief, logs and monitoring, deploying Bazar step by step, course recap and what to learn next
