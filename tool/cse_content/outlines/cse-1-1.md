# Course 1: Introduction to Computer Systems  (level id "deep-cse-1-1", lesson ids "deep-cse-1-1-01".."-25")
01 What a computer is: definition, characteristics, IPO model (input-process-output-storage)
02 History: abacus, Pascal, Babbage, Ada Lovelace, ENIAC, Turing, von Neumann, up to smartphones
03 Generations of computers (1st-5th): vacuum tube, transistor, IC, microprocessor, AI era
04 Types of computers: analog/digital/hybrid; super, mainframe, mini, micro, embedded, wearable
05 The parts of a computer system: hardware, software, firmware, data, people; von Neumann architecture
06 The CPU: ALU, control unit, registers, clock speed, cores, fetch-decode-execute cycle
07 Primary memory and the memory hierarchy: registers, cache, RAM (SRAM/DRAM), ROM types, virtual memory idea
08 Secondary storage: HDD, SSD, optical, flash/USB, memory cards, cloud storage; capacity units KB..TB
09 Input devices: keyboard, mouse, touch, scanner, mic, camera, sensors, OCR/OMR/MICR, barcode/QR
10 Output devices: monitors (LCD/LED/OLED, resolution, pixels), printers (inkjet/laser/3D), speakers, projectors
11 Motherboard, buses, ports and power: chipset, expansion slots, USB/HDMI, SMPS, booting & BIOS/UEFI
12 Number systems: binary, octal, decimal, hexadecimal and conversions (with worked examples)
13 Binary arithmetic: addition, subtraction, sign-magnitude, 1's and 2's complement, overflow
14 Data representation: bit/byte, ASCII, Unicode (Bangla text!), images (pixels, RGB), sound (sampling), compression
15 Boolean logic and logic gates: AND/OR/NOT/NAND/NOR/XOR, truth tables, simple circuits
16 Software: system vs application vs utility software; licenses (proprietary, open source, freeware, shareware)
17 Operating systems: what an OS does, types (batch, time-sharing, real-time, mobile), Windows/Linux/Android/macOS
18 Programming languages and translators: machine, assembly, high-level; compiler, interpreter, assembler
19 Problem solving: algorithms, flowcharts, pseudocode with examples
20 Files and file systems: files, folders, extensions, paths, backups
21 Computer networks: LAN/MAN/WAN, topologies, devices (router, switch), wired vs wireless
22 The Internet and the Web: IP address, DNS, client-server, HTTP/HTTPS, browser, email, search engines
23 Data, databases and information systems: data vs information, tables, records, DBMS basics
24 Computer security: malware types, phishing, passwords, 2FA, backups, safe browsing, privacy
25 Computers in society: applications (bank, health, education, e-gov in BD), ethics, careers, future (AI, cloud, IoT)
