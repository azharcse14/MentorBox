# Course 2: Structured Programming (C)  (level id "deep-cse-1-2", lesson ids "deep-cse-1-2-01".."-25")
01 Programming and the structured idea: program, algorithm, sequence/selection/iteration, goto problem, top-down design, short history of C
02 Your first C program: structure of a C program, #include, main(), printf, compile-link-run with gcc, IDEs, error types (syntax, linker, runtime, logical)
03 Building blocks: character set, tokens, keywords, identifiers and naming rules, variables, constants (literal, const, #define intro), comments
04 Data types: int, char, float, double, short/long/unsigned modifiers, sizeof, ranges, overflow, choosing the right type
05 Input and output: printf/scanf, format specifiers, the & in scanf, escape sequences, field width and precision, getchar/putchar
06 Operators and expressions: arithmetic, integer division and %, relational, logical (short-circuit), assignment and compound assignment, ++/-- prefix vs postfix
07 Precedence, type conversion and bitwise operators: precedence/associativity table, implicit conversion, casting, &, |, ^, ~, <<, >>
08 Decision making with if: if, if-else, nested if, else-if ladder, conditional operator ?:, dangling else, = vs ==
09 switch and jumps: switch-case, break, default, fall-through, when to use switch vs if, goto and why to avoid it
10 Loops: while, do-while, for; entry vs exit controlled, counters and accumulators, sum of series, digit problems
11 Loop control and nested loops: break, continue, infinite loops, nested loops, star patterns, prime check, multiplication table
12 Functions: why functions, library vs user-defined, prototype, definition, call, parameters vs arguments, return, void
13 Scope and storage classes: local/global/block scope, lifetime, auto, static, register, extern, call by value
14 Recursion: base case and recursive case, call stack, factorial, Fibonacci, GCD, sum of digits, recursion vs iteration
15 One-dimensional arrays: declaration, initialization, indexing from 0, traversal, sum/average/max, out-of-bounds danger, passing arrays to functions
16 Searching and sorting arrays: linear search, binary search, bubble sort, selection sort, step-by-step traces
17 Two-dimensional arrays: rows and columns, nested-loop traversal, matrix addition, transpose, multiplication
18 Strings: char arrays and the '\0' terminator, reading strings (scanf, fgets), string.h (strlen, strcpy, strcat, strcmp), palindrome and counting vowels
19 Pointers basics: memory addresses, & and *, declaring pointers, NULL, pointer size, pointer arithmetic
20 Pointers with arrays and functions: array name as pointer, call by reference (swap), passing arrays, returning multiple values, pointer to pointer, const pointers
21 Dynamic memory allocation: stack vs heap, malloc, calloc, realloc, free, memory leaks, dangling pointers, dynamic arrays
22 Structures, unions and enums: struct definition, member access (. and ->), nested structs, array of structs, typedef, union, enum
23 File handling: FILE pointer, fopen modes, fclose, fprintf/fscanf, fgetc/fputc, fgets/fputs, text vs binary, fread/fwrite, EOF and error checks
24 Preprocessor and program organisation: #include, #define and macros, conditional compilation, header files, multi-file programs, command-line arguments
25 Debugging, good style and a mini project: debugging methods, common C bugs, coding style, testing, student-result project tying everything together
