# Course: Database Management Systems  (level id "deep-cse-4-2", lesson ids "deep-cse-4-2-01".."-25")
Builds on Introduction to Computer Systems (deep-cse-1-1, lesson 23: data, tables, DBMS basics), Discrete Mathematics
(deep-cse-1-3, lesson 21: relations) and Data Structures (deep-cse-2-2, lesson 19: B-trees and B+ trees). Those are only
recapped; here the focus is how a real DBMS is designed and used: modelling, the relational model, SQL, design theory,
storage and indexing, query processing, transactions, concurrency, recovery, and modern databases. One running example
(a university database: student, course, enroll, department) is used across lessons; SQL examples are checked with sqlite3.
01 What a DBMS is: data vs information, the file-system way and its problems (redundancy, inconsistency, access, integrity, concurrency, security), what a DBMS adds, database users and the DBA, a short history (hierarchical, network, relational 1970, SQL, NoSQL)
02 DBMS architecture: schema vs instance, three-schema architecture (external, conceptual, internal), logical and physical data independence, data models overview, DDL/DML, DBMS components (query processor, storage manager, buffer, catalog), 1-tier/2-tier/3-tier
03 ER model I: entities and entity sets, attributes (simple/composite, single/multi-valued, derived, key), relationships and relationship sets, degree, cardinality ratios (1:1, 1:N, M:N), participation (total/partial), ER diagram symbols
04 ER model II and mapping: weak entities and identifying relationships, partial keys, specialization and generalization (disjoint/overlapping, total/partial), aggregation, design choices, step-by-step mapping of an ER diagram to tables
05 The relational model: relation, tuple, attribute, domain, degree and cardinality, properties of relations, keys (super, candidate, primary, alternate, foreign), NULL, integrity constraints (domain, entity, referential), ON DELETE actions
06 Relational algebra: selection, projection, union, set difference, intersection, Cartesian product, rename, joins (theta, equi, natural, outer), division, writing queries as expressions, a peek at tuple and domain relational calculus
07 SQL I, defining and changing data: SQL history and parts (DDL, DML, DCL, TCL), data types, CREATE TABLE with constraints (PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, CHECK, DEFAULT), ALTER, DROP, TRUNCATE, INSERT, UPDATE, DELETE
08 SQL II, basic queries: SELECT-FROM-WHERE, column aliases and expressions, DISTINCT, ORDER BY, LIMIT, BETWEEN, IN, LIKE patterns, NULL and three-valued logic, IS NULL, logical order of evaluation
09 SQL III, aggregates and grouping: COUNT/SUM/AVG/MIN/MAX, COUNT(*) vs COUNT(col), NULLs in aggregates, GROUP BY, HAVING vs WHERE, grouping rules, CASE expressions, worked report queries
10 SQL IV, joins: why joins, Cartesian product, INNER JOIN, NATURAL JOIN and USING, LEFT/RIGHT/FULL OUTER JOIN, self join, joining three tables, anti-join pattern with LEFT JOIN ... IS NULL
11 SQL V, subqueries, set operations and views: scalar subqueries, IN/NOT IN (and the NULL trap), EXISTS/NOT EXISTS, correlated subqueries, ALL/ANY, UNION/UNION ALL/INTERSECT/EXCEPT, WITH (CTE), views and updatable views
12 SQL VI, programming the database: indexes in SQL (CREATE INDEX), constraints vs triggers, triggers (BEFORE/AFTER, row-level), stored procedures and functions, cursors, GRANT/REVOKE, using SQL from programs with parameters
13 Functional dependencies: what an FD is, reading FDs from data, trivial FDs, Armstrong's axioms and derived rules, attribute closure X+, finding candidate keys, prime attributes, canonical (minimal) cover worked
14 Normalization I: the bad table and update/insert/delete anomalies, decomposition idea, 1NF, full and partial dependency, 2NF, transitive dependency, 3NF, worked step-by-step normalization of a results table
15 Normalization II: BCNF and how it differs from 3NF, BCNF decomposition algorithm, lossless-join test (common attributes form a key), dependency preservation, 3NF synthesis, multivalued dependencies and 4NF, 5NF in one line, denormalization
16 Storage and file organization: memory hierarchy, disks and SSDs, blocks/pages, fixed and variable-length records, slotted pages, heap, sorted and hashed files, buffer manager and replacement (LRU, clock), RAID levels 0/1/5
17 Indexing and hashing: why indexes, search key, dense vs sparse, primary (clustering) vs secondary indexes, multilevel indexes, B+ tree index (recap, fan-out, height math), static hashing, extendible hashing, bitmap indexes, cost of indexes
18 Query processing: steps (parse, translate, optimize, execute), measuring cost in block transfers, selection algorithms, external merge sort worked, join algorithms (nested loop, block nested loop, index nested loop, sort-merge, hash join) with costs, pipelining vs materialization
19 Query optimization: equivalent expressions and rules, heuristic optimization (push selections and projections down), query trees, statistics and selectivity estimates, join order and dynamic programming idea, EXPLAIN in practice
20 Transactions: what a transaction is, read/write model, ACID explained with a bKash transfer, transaction states, COMMIT/ROLLBACK, why concurrency (throughput), concurrency problems (lost update, dirty read, unrepeatable read, phantom), schedules (serial and concurrent)
21 Serializability and recoverability: conflicting operations, conflict equivalence, conflict serializability, precedence graph test worked, view serializability and blind writes, recoverable, cascadeless and strict schedules
22 Concurrency control: shared and exclusive locks, compatibility matrix, two-phase locking (basic, strict, rigorous), deadlocks (wait-for graph, wait-die, wound-wait, timeouts), lock granularity and intention locks, timestamp ordering, Thomas write rule, MVCC, SQL isolation levels
23 Recovery: failure types, stable storage, log records, write-ahead logging, deferred and immediate update, undo and redo, checkpoints, worked crash recovery, ARIES in brief, shadow paging, backups
24 NoSQL and distributed databases: why NoSQL, key-value, document, column-family and graph stores, replication, sharding/partitioning, CAP theorem, BASE vs ACID, eventual consistency, two-phase commit, choosing SQL vs NoSQL
25 Security, warehouses and wrap-up: authentication and authorization, roles, SQL injection and prepared statements, encryption, OLTP vs OLAP, data warehouse, ETL, star and snowflake schema, data mining in one line, course recap and what to learn next
